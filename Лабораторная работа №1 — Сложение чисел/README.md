# Лабораторная работа №1

## Тема: Сложение двух чисел на языке ассемблера NASM

### Цель работы

Познакомиться с языком ассемблера NASM, регистрами процессора, арифметическими инструкциями и вызовом внешней функции для вывода результата.

### Задание

Сложить два целых числа и вывести результат в консоль.

### Исходные данные

- Первое число: 15
- Второе число: 27

### Результат выполнения

```text
Сумма: 42
```

### Используемые инструкции

| Инструкция | Назначение |
|---|---|
| `mov` | Перемещение данных |
| `add` | Сложение |
| `lea` | Получение эффективного адреса |
| `xor` | Побитовое исключающее ИЛИ |
| `call` | Вызов функции |
| `ret` | Возврат управления |

### Среда разработки

- Операционная система: macOS
- Архитектура компьютера: ARM64 (Apple Silicon)
- Архитектура программы: x86-64
- Ассемблер: NASM 3.02
- Формат объектного файла: Mach-O 64-bit
- Компоновщик: Clang

**Примечание:** программа собрана для x86-64 и успешно запущена на Apple Silicon через Rosetta 2.

### Сборка и запуск на macOS

Установить NASM (если он ещё не установлен):

```bash
brew install nasm
```

Создать объектный файл:

```bash
nasm -f macho64 sur.asm -o sur.o
```

Скомпоновать программу:

```bash
clang -arch x86_64 sur.o -o sur -lSystem
```

Запустить:

```bash
./sur
```

### Подтверждение выполнения

Ожидаемый вывод:

```text
Сумма: 42
```
