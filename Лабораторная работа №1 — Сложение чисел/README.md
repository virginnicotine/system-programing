# Лабораторная работа №1

**Тема:** сложение двух чисел на NASM.

Программа складывает числа 15 и 27 и выводит результат в консоль.

**Результат:**
```text
Сумма: 42
```

**Сборка и запуск на macOS:**
```bash
nasm -f macho64 sur.asm -o sur.o
clang -arch x86_64 sur.o -o sur -Wl,-ld_classic
./sur
```
