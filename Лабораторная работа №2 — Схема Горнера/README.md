# Лабораторная работа №2

**Тема:** вычисление квадратного трёхчлена по схеме Горнера.

Программа вычисляет выражение:

`(a * x + b) * x + c`

Исходные данные: `a = 2`, `b = 3`, `c = 4`, `x = 5`.

**Результат:**
```text
Результат: 69
```

## Режимы адресации

- **Относительная адресация памяти** — `[rel a]`, `[rel b]`, `[rel c]`, `[rel x]`. Значения берутся из секции данных.
- **Регистровая адресация** — `eax` хранит промежуточный результат.
- **Относительная адресация для строки** — `[rel format_str]` передаёт адрес строки функции `printf`.

## Команды

- `mov` — загрузка значения в регистр.
- `imul` — умножение.
- `add` — сложение.
- `lea` — получение адреса строки.
- `xor` — обнуление регистра.
- `call` — вызов `printf`.
- `ret` — завершение функции.

## Разбор выражения (a + b) * (c - d)

1. `mov eax, [rel a]` — загрузить `a` в регистр.
2. `add eax, [rel b]` — прибавить `b`.
3. `mov ebx, [rel c]` — загрузить `c`.
4. `sub ebx, [rel d]` — вычесть `d`.
5. `imul eax, ebx` — умножить полученные результаты.

Здесь используются относительная адресация памяти для переменных и регистровая адресация для промежуточных результатов.
