# Лабораторная работа №2

**Тема:** схема Горнера.

Программа считает выражение `(a * x + b) * x + c`.

Данные: `a = 2`, `b = 3`, `c = 4`, `x = 5`.

**Результат:**
```text
Результат: 69
```

## Короткий разбор

- `mov` - записывает значение в регистр.
- `imul` - умножает числа.
- `add` - складывает числа.
- `[rel a]`, `[rel b]`, `[rel c]`, `[rel x]` - обращение к данным в памяти.
- `eax` - регистр, в котором хранится результат вычислений.

Во второй задаче для выражения `(a + b) * (c - d)` можно использовать `mov`, `add`, `sub` и `imul`. Переменные загружаются из памяти, а промежуточные результаты хранятся в регистрах.

## Запуск

```bash
nasm -f macho64 prac04.asm -o prac04.o
clang -arch x86_64 prac04.o -o prac04 -Wl,-ld_classic
./prac04
```
